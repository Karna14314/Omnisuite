🔍 Current UI Problems
6 critical issues identified across all screens
01

Only 2 Nav Tabs (Home + Tools)

Bottom nav is starved — no History, Files, or Settings tab. User has to hunt for features across horizontal scroll tabs instead.

02

Horizontal Category Tabs Cut Off

"Archive & Q…" is clipped and barely visible. Users can't discover what's there. Tab row doesn't afford scrolling visually.

03

Generic Emoji Icons

Tool cards use inconsistent emoji and stock icons with mismatched pastel circles. No visual cohesion or brand identity.

04

Large Wasted Empty Space

Documents tab has 40% dead whitespace at the bottom. Home screen wastes space with no CTA or file entry area visible.

05

No Visual Hierarchy / Accents

Everything is the same gray card on gray background. Category colors (red=PDF, green=Excel) are not used consistently.

06

Light Theme — High Eye Strain

Flat white/gray light theme looks corporate and low-contrast. Dark mode exists in Settings but is not the default premium look.

📐 Design Principles
What every screen must obey
🌑

Dark-First Default

Background #0D0F14, surfaces #161922. Users spending time with documents need low eye strain. Dark is the canonical theme — light is the accessibility variant.

🎯

5-Tab Bottom Nav

Home · Tools · Files · History · Settings. All primary destinations one tap away. No hidden horizontal tabs for top-level categories.

🎨

Semantic Color Coding

Every tool category has a signature color that appears on icons, borders, labels, and headers. User learns the language once, navigates forever.

📋

List Rows for 5+ Tools

2×2 card grid only for max 4 featured items. Tool detail lists (PDF, Archive tabs) use full-width rows for scannability — title, subtitle, chevron.

⚡

No Wasted Space

Every screen viewport fills with useful content. Recents carousel, quick pickers, file types — stacked for dense but uncluttered information.

✏️

DM Sans + Syne Typography

Syne 800 for screen titles and brand identity. DM Sans 400/600/700 for body, labels, and card titles. No generic system fonts.

### TOOLS SCREEN (AllToolsScreen.kt) — Redesign tab structure

Keep ScrollableTabRow but add ICONS to each tab + use semantic colors for active indicator:

Replace 2-column card grid with full-width ToolListRow composable:
```kotlin
@Composable
fun ToolListRow(icon: String, title: String, subtitle: String, accentColor: Color, onClick: () -> Unit) {
    Row(
        modifier = Modifier
            .fillMaxWidth()
            .clip(RoundedCornerShape(14.dp))
            .background(Surface2)
            .border(1.dp, Border, RoundedCornerShape(14.dp))
            .clickable(onClick = onClick)
            .padding(12.dp, 12.dp),
        verticalAlignment = Alignment.CenterVertically
    ) {
        Box(Modifier.size(36.dp).clip(RoundedCornerShape(10.dp))
            .background(accentColor.copy(alpha = 0.12f)),
            contentAlignment = Alignment.Center) { Text(icon, fontSize = 17.sp) }
        Spacer(Modifier.width(12.dp))
        Column(Modifier.weight(1f)) {
            Text(title, style = MaterialTheme.typography.titleSmall, fontWeight = FontWeight.Bold)
            Text(subtitle, style = MaterialTheme.typography.bodySmall, color = TextMuted)
        }
        Icon(Icons.Rounded.ChevronRight, null, tint = TextMuted)
    }
}
```
