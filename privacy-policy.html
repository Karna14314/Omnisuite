1 Introduction

OmniSuite ("the Application," "we," "us," or "our") is an all-in-one document viewer and productivity suite for Android. It supports PDF, DOCX, XLSX, PPTX, TXT, CSV, and image formats alongside tools such as QR code generation, OCR text extraction, image editing, and file compression.

This Privacy Policy describes what information the Application accesses, how it is processed, how it is stored, and what rights you have concerning your data. By installing or using OmniSuite, you acknowledge and agree to the practices described in this document. If you do not agree, please uninstall the Application.

This policy applies to all versions of OmniSuite distributed through the Google Play Store and any other authorized distribution channel.

2 Offline Architecture

Key Commitment

OmniSuite is engineered to operate entirely offline. The Application contains no network adapters, no HTTP clients, no cloud API integrations, and no analytics or telemetry frameworks. All document processing, rendering, and tool operations execute exclusively on your device.

Because the Application has no network connectivity, it is technically impossible for us — or any third party — to access, collect, transmit, or monitor your documents, files, usage patterns, or personal information through the Application.

The Application does not contain advertising SDKs, crash reporting services (such as Firebase Crashlytics), or analytics platforms (such as Google Analytics or Mixpanel). No data of any kind leaves your device.

3 Data Collection

Information We Do Not Collect

OmniSuite does not collect, process, or store any of the following:

  • Personal identifiers (name, email address, phone number, date of birth)
  • Device identifiers (Android ID, IMEI, serial number, advertising ID)
  • Location data (GPS, Wi-Fi-based, or cell-tower-based)
  • IP addresses or network information
  • Browsing history, search queries, or usage analytics
  • Biometric data
  • Financial or payment information
  • Contacts, call logs, or SMS messages

Information Processed Locally

The following data is processed strictly on-device and is never transmitted externally:

  • Document content: Files you open (PDF, DOCX, XLSX, PPTX, TXT, CSV, images) are read into device memory for rendering and discarded when the viewer session ends.
  • Recent file records: File names, URIs, MIME types, and timestamps are stored in a local SQLite database to populate the "Recent Files" list on the home screen.
  • Temporary cached files: Content stream copies are written to the Application's private cache directory for document engine processing.
  • QR code payloads: Text, URLs, contacts, Wi-Fi credentials, and other data you enter for QR generation are processed in memory and never persisted beyond the active session.

Data Sharing

We do not sell, rent, license, trade, or disclose any user data to third parties — including advertising networks, data brokers, marketing partners, analytics providers, or government entities. Since no data is collected, there is no data to share.

4 Device Permissions

OmniSuite requests the minimum set of Android runtime permissions necessary for its core features. Each permission is used exclusively for the purpose described below:

Storage / Storage Access Framework (SAF)
Required to browse, open, read, and save files that you explicitly select through the system file picker. Persistent URI permissions are obtained via takePersistableUriPermission() to maintain access to previously opened documents across device reboots without requiring repeated user selection.
Camera
Used exclusively for the real-time QR code and barcode scanner. Camera frames are processed locally using CameraX and Google ML Kit's on-device barcode detection. No images or video are captured, recorded, or stored.
Clipboard
Accessed only when you explicitly initiate a copy action — for example, copying OCR-extracted text, PDF page content, or a generated QR code payload to the system clipboard.

OmniSuite does not request permissions for location, microphone, contacts, phone state, SMS, Bluetooth, or background activity.

5 Local Storage & Cache

To deliver fast, reliable document viewing, the Application maintains data locally within its sandboxed storage area:

Recent Files Database

A local SQLite database (managed via Android Room) stores metadata about files you have opened: file name, content URI, MIME type, and last-opened timestamp. This data is used solely to display your recent files list and is never exported or transmitted. You may clear this history at any time through the Settings screen.

Temporary File Cache

Documents opened through SAF content streams are temporarily copied to the Application's private cache directory (context.cacheDir) to provide the file path references required by document processing engines such as Apache POI. These cached files:

  • Reside exclusively within the Application's sandboxed storage.
  • Are inaccessible to other applications on the device.
  • Are subject to automatic size-based pruning — the cache is capped at 50 MB, and the oldest files are deleted automatically when the threshold is exceeded.
  • Can be manually cleared at any time via Settings → Clear Cache.
  • Are automatically deleted by the Android operating system when the Application is uninstalled.

Generated Files

Files you explicitly create — such as QR code images, watermarked PDFs, compressed ZIP archives, or signed documents — are saved to a location you choose through the system file picker. These files are owned by you and are not managed, tracked, or accessed by the Application after creation.

6 Data Retention

Since OmniSuite operates entirely offline and collects no personal data, there is no remote data retention to disclose. All locally stored data follows this retention schedule:

  • Recent files database: Retained until you manually clear the history via Settings, or until the Application is uninstalled.
  • Cached files: Automatically pruned when total cache size exceeds 50 MB. Also cleared on manual cache purge or Application uninstall.
  • In-memory document data: Discarded immediately when a viewer session ends or the Application process is terminated.

You retain full control over all locally stored data and may delete it at any time without contacting us.

7 Data Security

We implement the following measures to protect any data the Application processes on your device:

  • Android Application Sandbox: All Application data, including the cache directory and database, is stored within the Application's private sandboxed storage, which is inaccessible to other applications under standard Android security policies.
  • No Network Surface: The complete absence of network connectivity eliminates entire categories of security threats, including man-in-the-middle attacks, data interception, remote exploitation, and unauthorized data exfiltration.
  • Storage Access Framework: File access is mediated through Android's SAF, which ensures that the Application can only access files you explicitly select — it cannot scan, index, or access arbitrary files on your device.
  • Code Obfuscation: Release builds use R8 code shrinking and obfuscation with custom ProGuard rules to reduce the attack surface of the compiled application.

While no system can guarantee absolute security, the offline-only architecture of OmniSuite eliminates the most common vectors for data breaches in mobile applications.

8 Third-Party Libraries

OmniSuite uses open-source libraries to perform document processing and utility operations. All libraries execute exclusively on-device with no network capabilities within this Application:

  • Apache POI: Reads and processes Microsoft Office formats (DOCX, XLSX, PPTX) locally on the device.
  • PDFBox-Android (Tom Roush): Renders, extracts text from, and processes PDF documents locally.
  • Google ML Kit (Text Recognition): Performs optical character recognition (OCR) using on-device machine learning models. The ML Kit module used is the bundled offline variant and does not communicate with Google servers.
  • ZXing: Generates and decodes QR codes and barcodes locally.
  • Coil: Loads and displays images from local file paths within the Application's image viewer.
  • Jetpack Compose & AndroidX: Provides the UI framework and architecture components. These libraries do not collect or transmit user data.

None of these libraries collect telemetry, transmit usage data, or make network connections within the context of this Application. We do not use any third-party advertising, analytics, or tracking SDKs.

9 Children's Privacy

OmniSuite does not collect personal information from any user, including children under the age of 13 (or the applicable age of consent in your jurisdiction). Because the Application is fully offline and collects no data, it complies with:

  • The Children's Online Privacy Protection Act (COPPA) — United States
  • The Age Appropriate Design Code (AADC) — United Kingdom
  • Article 8 of the General Data Protection Regulation (GDPR) — European Union

Parents and guardians can allow children to use the Application without privacy concerns, as no data collection mechanism exists within the Application.

10 Your Rights

Although OmniSuite does not collect personal data, we respect your right to understand and control how software operates on your device. Under applicable privacy regulations, you may have the following rights:

  • Right to Access: You may request information about what data, if any, is associated with your use. As stated in this policy, no personal data is collected or stored remotely.
  • Right to Deletion: All locally stored data (recent files history, cache) can be deleted at any time through the Application's Settings screen, or by uninstalling the Application.
  • Right to Restrict Processing: You may revoke any runtime permission (Storage, Camera) through your device's system settings at any time. Revoking permissions may limit certain features.
  • Right to Data Portability: Since no personal data is collected or stored remotely, there is no data to export.
  • Right to Object: The Application does not engage in profiling, automated decision-making, or targeted advertising.

To exercise any of these rights or if you have questions, please contact us using the information provided in the Contact Us section below.

11 Regulatory Compliance

OmniSuite's offline-only, zero-collection architecture ensures compliance with the following data protection regulations:
